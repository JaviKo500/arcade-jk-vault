## Critical: read the docs before writing code

This repo pins `next@16.3.0`, a version newer than most training data and with breaking API/convention changes. **Before writing any Next.js code, read the relevant guide under `node_modules/next/dist/docs/`** (sections: `01-app`, `02-pages`, `03-architecture`, `04-community`). Do not assume App Router APIs work the way they did in older Next.js versions you may recall — verify against these docs first, and heed any deprecation notices found there.

The `AGENTS.md` file (imported above) is regenerated by `next dev` itself (see `node_modules/next/dist/server/lib/generate-agent-files.js`). If it shows as a diff, that's expected — commit it along with your work rather than reverting it, since removing it just causes `next dev` to recreate the uncommitted change.

## Architecture

- App Router only (`app/` directory) — `app/layout.tsx` is the root layout, `app/page.tsx` the home route.
- Root layout's props are typed with the generated `LayoutProps<"/">` helper (from `.next/types`) rather than a hand-written props interface — this is a Next.js 16 typed-routes convention, not a mistake to "fix" if it looks unfamiliar.
- Styling is Tailwind CSS v4, configured CSS-first: `app/globals.css` uses `@import "tailwindcss"` and defines theme tokens via `@theme inline` (no `tailwind.config.js`). PostCSS is wired through `@tailwindcss/postcss` in `postcss.config.mjs`.
- Path alias `@/*` maps to the repo root (`tsconfig.json`).
- The project currently contains only the default `create-next-app` scaffold — no app-specific routes, components, or game/scoring logic exist yet.
